# Tango icons

The PNG files in this directory are from the Tango Desktop Project's icon theme
(http://tango.freedesktop.org/Tango_Desktop_Project), used by the Express
theme in place of some of the app's line icons.

- License: public domain. The theme's `COPYING` reads: "The icons in this
  repository are herefore released into the Public Domain." (SPDX: CC0-1.0)
- Source: `tango-icon-theme` 0.8.90, the 16x16 and 32x32 bitmaps.

Each icon keeps its Tango name with its pixel size appended, for example
`internet-mail-16.png`. The files were copied unchanged apart from removing
embedded metadata.

`star.svg`, `tag.svg`, `tags.svg`, `mail.svg`, `user.svg`, `map-pin.svg`,
`clock.svg`, `phone.svg`, `cards.svg`, `table.svg`, `focus.svg` and `eye.svg` are not from Tango, which has no matching icons. They were drawn
for this project in Tango's style and palette, and are covered by the
project's own license.

`folder-cog`, `folder-pen` and `folder-output` put a Tango picture, scaled
down, on the corner of Tango's `folder`, as Tango puts emblems on icons: the
`emblem-system` gear, `accessories-text-editor` and the `go-up` arrow. All
of them are Tango's public-domain pictures.
