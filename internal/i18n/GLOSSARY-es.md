# Spanish glossary

These are the words Gofer's Spanish catalog (`locales/es.json`) uses for its core terms. Keep new messages consistent with them.

The text is neutral Spanish that addresses the reader as *tú* ("Elige", "tu cuenta").

| English | Spanish |
|---|---|
| Inbox | Recibidos |
| Sent | Enviados |
| Drafts | Borradores |
| Spam | Spam |
| Trash | Papelera |
| Archive | Archivo |
| Starred | Destacados |
| Scheduled | Programados |
| Folder | Carpeta |
| Label / tag | Etiqueta |
| Thread / conversation | Conversación |
| Compose | Redactar |
| Reply / Reply all | Responder / Responder a todos |
| Forward | Reenviar |
| Attachment | Archivo adjunto |
| Mark as read / unread | Marcar como leído / no leído |
| Move to | Mover a |
| Schedule send | Programar envío |
| Sender / recipient | Remitente / destinatario |
| Subject | Asunto |
