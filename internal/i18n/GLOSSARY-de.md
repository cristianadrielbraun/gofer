# German glossary

These are the words Gofer's German catalog (`locales/de.json`) uses for its core terms. Keep new messages consistent with them.

The German text addresses the reader informally using **du** ("Wähle", "dein Konto"). Prefer concise, natural German UI wording over literal translations.

## Style notes

- Use informal address (du/dein/dir) consistently when addressing the user.
- Prefer short, clear labels suitable for buttons and menus.
- Keep established technical terms such as *Passkey*, *IMAP*, *SMTP*, and *JMAP* unchanged.
- Use *Unterhaltung* for an email thread/conversation, rather than switching between several terms.
- Use *Label* or *Bezeichnung* consistently within the same UI context; avoid mixing terminology without a reason.
